# The-Digital-Repository-for-CSE-Academic-Content
GNIT Repository is a role-based academic content management system for CSE departments. Students access filtered notes, videos, assignments &amp; PYQs. Faculty upload resources, mark live attendance (Present/Absent/Late), and generate PDF reports. Admin manages subjects and approves faculty registrations. Built with PHP, MySQL, Bootstrap.
Key Features
Role-Based Access Control: Separate dashboards for Students, Faculty, and Administrators with custom permissions.
Smart Resource Filtering: Automatically displays content based on student's branch, year, and semester.
Live Attendance System: Faculty marks attendance as Present/Absent/Late with automatic percentage calculation.
Personal Notes: Students can create, edit, and save personal study notes in the database.
PDF Report Generation: Generates professional, print-ready attendance reports for individual sessions or complete semester.
Bulk Subject Import: CSV file upload for adding multiple subjects at once.
Faculty Approval Workflow: Admin must approve faculty registrations before login access.
Download Analytics: Tracks downloads and views for each resource.
YouTube Video Integration: Auto-converts YouTube URLs to embed format for seamless playback.
